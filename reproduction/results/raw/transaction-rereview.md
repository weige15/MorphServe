## Review

- **Finding: P1 — CUDA overlap analysis does not fail closed when stream metadata is absent.** `reproduction/runtime/morphserve/trace_analysis.py:73-79` only rejects a kernel when `copy_stream` is non-null and equal to the kernel stream. If either activity lacks stream metadata, the analyzer can accept it as cross-stream overlap, contradicting the protocol’s requirement to fail closed when streams cannot be established. Add explicit non-null checks for both streams and tests covering missing copy-stream and kernel-stream metadata.

- **Finding: P2 — Poisoned recovery reattaches a potentially invalid KV snapshot.** `reproduction/runtime/morphserve/real_executor.py:243-257` unconditionally calls `_restore_kv_state(snapshot)` after restoration failure. If `restore_fp16()` suffered a rollback-copy failure, it has already set `poisoned=True` and left a truthful mixed FP16/W4 state; reattaching all old KV groups can attach reclaimed views to a layer now restored to FP16. Serving is correctly disabled, limiting impact, but diagnostic state is no longer truthful. Restore the snapshot only when rollback completed without poisoning; add a `recover_fp16()` double-copy-failure test.

- **Finding: P2 — “Ordinary preemptions” remains a queue-length proxy, not a measured counter.** `reproduction/scripts/multirequest_ownership.py:55,123-126` uses a static `SimpleNamespace` scheduler and computes preemptions only from final swapped-queue length growth. This cannot observe transient swap-out/swap-in activity and is tautologically zero in this pilot. Relabel the gate as scheduler queue mutation evidence, or instrument a cumulative preemption counter in a real scheduler.

- **Merge verdict: BLOCK.** Atomic recovery compensation, checked pressure rollback, truthful poisoned controller state, direct double-copy failure handling, and allocator/refusal gates are substantially repaired. The remaining P1 permits false-positive “actual CUDA cross-stream overlap” evidence and should be fixed before the strengthened GPU rerun is trusted.
